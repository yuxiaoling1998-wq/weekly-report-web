# 目标周报 · 网页版

无需安装 Python。通过 GitHub Pages 打开网页，连接自己的 GitHub 私有数据仓库。

## 发布

将此文件夹内的网页文件上传到公开的 `weekly-report-web` 仓库根目录。
进入 Settings → Pages，选择 Deploy from a branch → main → / (root) → Save。

本项目默认用户名为 `yuxiaoling1998-wq`，数据仓库为 `weekly-report-data`，可以在网页中更改。

## 数据与授权

1. 创建一个私有的 `weekly-report-data` 仓库，勾选 Add a README file。
2. 创建 Fine-grained personal access token，仅选择数据仓库，授予 Contents: Read and write，并设置到期时间。
3. 在网页填写用户名、数据仓库名称和令牌。令牌只在当前页面内存保存，不写入存储；刷新或关闭页面后需重新填写。
4. 创建目标并保存每日记录。数据存入私有仓库根目录的 `weekly-data.json`。
5. 每次切换设备，打开网页并连接，或点击“读取最新记录”。

网页不会轮询自动更新，不提供离线打开网站或离线自动上传队列。网络失败时会保留本机表单草稿，联网后需要再次点击保存。
同一条记录发生冲突时会展示云端和本机两个版本。不同记录的修改会保留并合并；保存不会强制覆盖整个仓库。

## 旧数据迁移

使用本地工具导出的 `weekly-data.json`，在网页“连接设置 → 迁移与备份”选择文件，确认导入。
仅允许导入空的数据仓库。已有数据不会被导入操作覆盖。

原始 Markdown 和 JSON 文件应单独留作备份。网页版使用一个 JSON 数据文件，并支持下载 Markdown 周报及完整 JSON 备份；本地 Python 版与网页版不会自动双向同步。

## 隐私

- 此公开仓库只保存通用网页代码，不包含个人记录或令牌。
- 不要将 `data/`、`reports/`、`weekly-data.json`、本地备份上传到此公开仓库。
- 私有记录在浏览器内渲染，不写入 Pages 发布文件；写入前会检查数据仓库为私有。
- 未提交的表单草稿保存在浏览器本地存储，按用户名和仓库隔离。共享设备使用后请清除草稿并断开连接。
- 不加载第三方脚本、字体或统计代码。令牌只发送至 GitHub API。
- 目前适合个人文字记录，单个数据文件上限为 900 KB；接近上限时会拒绝写入并提示备份扩容。

## 开发验证

纯 JavaScript ES modules，无构建步骤，无第三方依赖。测试位于本地项目的 `tests/web.test.mjs`。
